# 宠物蛋系统

## 目的

宠物蛋系统把学生长期、持续的书法练习转化为可感知的成长反馈。它服务于学习过程，不构成独立的收集或对战游戏。

## 已确认规则

- 每个碑帖对应一套宠物蛋与孵化后宠物形象。
- 学生学习某一碑帖时，为该碑帖积累经验值。
- 经验值达到规定阈值后，对应宠物蛋可以孵化为宠物。
- 不同学生对同一碑帖拥有各自的经验值和孵化状态。
- 孵化进度属于学习记录，不依赖微信 OpenID、客户端类型或图片文件路径。

概念关系如下：

```text
Copybook ──定义──> PetEggAppearance ──孵化为──> PetAppearance

Student ──┐
          ├──> StudentCopybookProgress
Copybook ─┘        ├── experience
                   ├── hatchThreshold
                   └── hatchState
```

`PetEggAppearance` 和 `PetAppearance` 表示碑帖对应的形象定义；`StudentCopybookProgress` 表示某个学生学习该碑帖时产生的实际进度。形象可以被多个学生复用，进度不能共享。

## 当前状态边界

当前至少需要表达以下状态：

```text
EGG → HATCHED
```

是否增加“破壳中”等中间状态、孵化后的成长阶段，以及经验值的具体计算方式，留到功能规格阶段确定，不由资源文件名或首版实现隐式决定。
